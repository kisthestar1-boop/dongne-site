# 다이어트댄스 — 우수 사이트 분석 (11/20)
참고: 305 Fitness, DivaDance, Powerhouse Dance, Pure Barre, DanceBody, Rumble Boxing
+ MarketMuscles / Gymdesk / thestacc 전환 분석

## 공통으로 잘하는 것
1. 첫 화면 = 실제 수업 사진/영상 (스톡·일러스트 X) — 신뢰의 핵심
2. 첫 화면에 "첫 수업 제안" (Diva: 2주 $59 / Pure Barre: free intro / 305: SAVE YOUR SPOT)
3. 맨 위 띠 배너로 기간 혜택
4. "처음 오세요?(New here?)" 메뉴·섹션 — 준비물·도착·뒷줄 등 첫 방문 불안 해소
5. 평점 배지(★4.9 · 리뷰 수)를 첫 화면 근처에
6. 가치 3카드: 잘난척 없는 강사 / 몸매 상관없음 / 나를 위한 시간 (Diva)
7. "Bring your crew" 친구 추천 (305)
8. 커뮤니티 사진 모자이크 "Inside Rumble"
9. 원장(창업자) 이야기 + 사진 (DanceBody)
10. 거대한 2색 헤드라인 + 어두운 배경 + 한 가지 강한 포인트색 (305 핑크, Rumble 빨강)

## 장유 적용 (한국 30~50대 여성)
- 걱정: 몸치 / 나이 / 살 / 혼자 / 상담 강요 / 주차 / 샤워
- 시간: 오전 10시(등원 후) · 저녁 8시(퇴근 후)
- 법: 다이어트댄스는 보통 학원법 대상 아님(체육·자유업) → 학원등록번호 X, 사업자 정보 표시
- 과장 금지: "한 달 -5kg" 같은 효과 보장 문구 X (표시광고법)
- 움직임: 민성님 취향상 흐르는 마퀴 대신 고정 띠, 영상은 천천히·카메라 고정
