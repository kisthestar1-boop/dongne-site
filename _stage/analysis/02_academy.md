# 새봄 영어수학 — 1등 학원 사이트 분석 (11/20)
참고: Mathnasium(무료 진단→맞춤 플랜→진도), vida.io 튜터링 사이트 20선 정리, Explore Learning, 국내 대치 학원 관행

## 왜 지금 시안은 "굳이 안 가겠다" 싶은가
- 첫 화면이 귀여운 캐릭터 → 성적 · 관리 학원이 아니라 유아 놀이처럼 보임 (AI 티)
- 증거가 없음: "다릅니다" 말만 있고 실제 결과 · 리포트 · 교실 모습이 없음
- 교습비가 안 보임 (학원법 표시 의무 + 학부모가 가장 먼저 찾는 것)
- 강사 사진이 증명사진 · 스튜디오 → 실제 가르치는 모습이 아님
- 원장님 직통 연락처가 약함

## 1등 사이트 공통 공식
1. 첫 문장 = 학부모 걱정 ("학원 다니는데 성적은 왜 그대로일까요?")
2. 버튼은 하나 (무료 레벨테스트) — 모든 섹션 끝에 반복
3. 숫자로 된 증거 (전·후 점수, 몇 주 만에)
4. "보여 주기" > "말하기": 실제 리포트 샘플, 수업 영상, 교실
5. 과정 3~4단계 (진단 → 맞춤 계획 → 수업 → 매주 리포트)
6. 가격 공개로 스스로 판단
7. 원장 이야기 (왜 이 학원을 하는지)

## 새봄 새 구성
히어로(실사 수업 영상 + 걱정 문장 + 레벨테스트 + 원장 직통)
→ 걱정 3가지 공감 → 매주 리포트 문자 실물(휴대폰) → 성적 변화 사례 3
→ 진행 4단계 → 과정 · 교습비 표 → 학교별 시간표 → 원장 · 강사(수업 중 사진)
→ 학부모 후기 → 이번 달 남은 자리 + 신청 → FAQ → 오시는 길 · 등록번호
